JobShield AI

This system is designed to detect whether a job advertisement is real or fake. It analyzes the content of job postings using a hybrid of a trained machine learning model and rule-based scam-pattern checks, and gives a clear prediction with a confidence score to help users avoid fraudulent opportunities.

⚙ How It Works
1

Text Preprocessing

The job description is cleaned and lemmatized using NLP techniques.

2

Feature Extraction

Text is converted into numerical features using TF-IDF (unigrams + bigrams).

3

ML Model Prediction

A neural network (MLP Classifier) estimates the probability the posting is fraudulent.

4

Rule-Based Check

Known scam phrases are weighted by severity, not treated as an automatic override.

5

Vagueness Check

Flags postings that are short, name no company, and give no way to apply — common in thin scam listings.

6

AI Reasoning (optional)

An open-weight LLM (Llama 3.3 via Groq) gives its own fraud score plus a plain-English explanation, when configured.

7

Final Decision

All signals combine as a probabilistic OR — any one can independently flag Fake, but one weak phrase alone can't.
